## اختصار المظهر: ما يمكن إثباته

النسخة الحالية لا تحتوي ربطًا لاختصار مباشر للمظهر، ونسخة Git المتاحة تحتوي commit واحدًا فقط؛ لا يمكن إثبات مفتاح سابق أو استعادته بأمان. لم يُخترع اختصار جديد أو يُستبدل اختصار قائم. أمر «تبديل المظهر الفاتح / الداكن» متاح بالوصول إلى **قائمة الأوامر الحالية Cmd/Ctrl+K**. استعادة اختصار مباشر بعينه تحتاج معرفة الربط السابق.

## نتائج التحقق

- `npm run build`: ناجح، بما فيه حزم العميل والخادم. لم تُنفّذ هجرة قاعدة بيانات خارجية: لا يوجد `DATABASE_URL` في بيئة التحقق.
- `npm run typecheck`: ناجح.
- `npm run lint`: صفر أخطاء؛ 6 تحذيرات Fast Refresh في ملفات موجودة سابقًا.
- `npm test`: **602 اختبار ناجح** (37 Gumroad + 565 في المجموعة الأساسية).
- جميع `src/lib/editor/*.test.ts`: **345 اختبار ناجح**؛ يشمل اختبارات Pointer Events وSVG والمكتبة/السحب والاستيراد والتصدير والتخزين ونموذج المحاذاة/التحويل.
- `scripts/test-editor-workspace.mjs`: **47 فحص متصفح ناجح**، باستخدام agent-browser وChromium. يتضمن:
  - Light/Dark، اختيار حصري ومزامنة حالة المظهر دون تغيير الخلفيات أو بيانات العناصر.
  - Ctrl+A وCmd+A، الاختصار العربي، التحديد المتعدد، Align/Distribute، Zoom عند 20/40/100/200%، ثبات أبعاد UI، وFit مع الاسم.
  - استقلال الاسم والتسمية، تبديل الصفحات، شريط من 30 صفحة ثابت الارتفاع، وإظهار الصفحة النشطة.
  - Group/Ungroup، تحديد أبناء المجموعة، Lock، كتابة الحقول، سحب التحديد المتعدد بالماوس ثم Undo كخطوة واحدة.
  - أحجام iPad **768×1024، 820×1180، 1024×768، 1180×820، 1366×1024**؛ حدود الأدراج، قابلية الوصول لأزرار الإغلاق والتبويبات، وأهداف لمس 44px.
  - Touch selection وPinch باستخدام أحداث لمس Chromium الأصلية عبر CDP، لا استدعاء `setZoom` بدل الإيماءة.
  - صفر أخطاء JavaScript غير معالجة في تشغيل المتصفح النهائي.
- تمت معاينة صور Light/Dark وصور التابلت؛ نواتج الاختبار محفوظة محليًا تحت `screenshots/editor-focused/` ومستبعدة من Git.

- اختبارات المكتبة والمشاريع وSVG والتصدير/الملفات القديمة تغطيها الاختبارات الآلية القائمة؛ لم يُنفّذ تنزيل إنتاجي بحساب مرخّص أو مزامنة مشروع سحابي حقيقي.

## إعادة تشغيل فحص المتصفح

يتطلب dev server و`agent-browser` مع Chromium صالح. يستخدم الاختبار جلسة معزولة باسم `nasaq-workspace-qa` وينشئ بيانات محلية مؤقتة؛ لا تشغّله على جلسة مشروع حقيقي.

```sh
npm run dev
# في عملية أخرى:
AGENT_BROWSER=/path/to/agent-browser node scripts/test-editor-workspace.mjs
```

يمكن تهيئة مسار Chromium أو اتصال CDP في جلسة agent-browser نفسها قبل التشغيل. لا يحتاج الاختبار أي اعتماديات إنتاج جديدة.

لم يُنفّذ commit أو push أو merge.
