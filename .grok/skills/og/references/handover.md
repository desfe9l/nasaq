# Atomic asset hand-over

Write generated bytes to a staging path outside `public/`, then use the
repository hand-over helper. A rename is atomic on the workspace filesystem;
`public/` is rejected as a staging directory because the build copies it
verbatim. These commands are the supported hand-over forms:

```sh
node scripts/write-atomic.mjs .grok/og.jpg.tmp public/og.jpg
node scripts/write-atomic.mjs .grok/x-banner.jpg.tmp public/x-banner.jpg
node scripts/write-atomic.mjs .grok/site.json.tmp src/lib/og/site.json
```

The helper accepts one staged file and one target. Stage all outputs before
running the corresponding command; do not hand off a half-written file or place
a temporary file under `public/`.

After hand-over, validate the actual files and metadata:

```sh
node scripts/brand-check.mjs
```
